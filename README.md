# ESCAPE FROM MURINO
> Из Мурино нет выхода.

Вы открываете глаза и понимаете, что находитесь не в своей кровати, а на холодной земле у какого-то подъезда. Вокруг какие то пауки, так называемые the fog, и странные... люди? Вам предстоит найти способ сбежать из Мурино, помогая персонажам.

Только запомните - **Мурино никогда не спит**.
